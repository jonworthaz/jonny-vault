Super Appmodular mini apps

One shell, many mini apps

Each module is a small, fast, self-contained app that snaps into the bottom-right corner so you can use it while you work. They all share the same dock container and speak a common module protocol, so they can be embedded, controlled, and have their data exported / imported by a host — like this super app.

How the modules plug in. Each is hosted here in an <iframe> and driven over postMessage: the super app sends module:open / module:close / module:setTheme, and — for portability — module:export (the module returns its data as JSON) and module:import (the host injects data back in). Export all gathers the JSON from Track & Plan into one file; Import all pushes it back. Drop these same modules into any other app the same way. Each keeps its own colour scheme.

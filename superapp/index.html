Super Appmodular mini apps

One shell, many mini apps

Each module is a small, fast, self-contained app that snaps into the corner so you can use it while you work. They share the same dock container and a common module protocol, so any host — like this super app — can embed, control, and export/import their data. Each keeps its own colour.

How the modules plug in. Each is hosted here in an <iframe> and driven over postMessage: the super app sends module:open / module:close / module:setTheme, and — for portability — module:export (a module returns its data as JSON) and module:import (the host injects it back). Export all gathers JSON from every module into one file; Import all pushes it back. Drop any of these modules into another app the same way.
